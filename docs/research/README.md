# Research

研究文件依用途分層：

```text
research/
├── raw-reports/
├── translated/
└── notes/
```

開發時優先看 `notes/`，需要完整背景或來源脈絡時再回到 `raw-reports/` 與 `translated/`。

目前最常用的起點：

- `notes/00-畢業專題需求整理.md`
- `notes/02-音訊擷取技術研究.md`
- `notes/03-即時逐字稿系統研究.md`
- `notes/09-模型供應商與自帶金鑰研究.md`
- `notes/10-SwiftUI輕量會議助理架構與介面設計.md`
- `notes/15-一學期畢業專題最小可行產品實作規劃.md`
